# 海龟汤直播游戏

2026-11-05：按已确认的阁楼黑板设计接入。首版12道固定轻悬疑题，合作破案，不计积分；每题6分钟，从汤面语音实际读完后开始计时。复用原采集页面。

## 主播口令

- `海龟汤`：从听歌场景进入准备页。
- `开始煮汤`：抽题、朗读汤面，语音自然结束后开始收问。
- `给个提示`：在当前回答结束后使用，每题最多两个提示。
- `公布汤底`：停止收问、撤销旧裁判结果，揭底讲解。
- `返回听歌`：结束循环，当前歌曲与同一条点歌队列继续播放。

与“你画我猜”互斥，切换游戏前先返回听歌。主播识别沿用现有昵称匹配机制。海龟汤需要现有DeepSeek配置与语音播报开启。

## 观众参与与节奏

发送`问：你的问题`，或`猜：完整真相`（英文冒号也可）。普通聊天不会触发游戏判题或闲聊语音。

- 收问15秒；达到2个候选且已等待5秒可提前处理；猜测优先进入裁判批次。
- 每人每轮一个候选，同一昵称最多一个待处理问题；猜测至少间隔15秒。
- 候选池最多32条问题与12条猜测，45秒过期。进入候选不承诺逐条回答。
- 精确重复合并，已答过的原问题提示已有判定。模型每批精选最多两个代表问题，相近问题合并。
- 只为选中的问题创建语音队列，实际播完一条再回答下一条；本批未选问题不继续积压，回答期间的新问题留待下一轮。
- 模型返回固定判定枚举及已知线索ID。自由解释、非法线索或不完整破案依据会被拦截。失败或12秒超时后提示重新提问，不改写故事。
- 首次确认关键线索者记为贡献者；完整说明核心因果者为破案者，揭底时点名感谢。

约2、4分钟给预设提示；持续两轮无人提问且开场至少45秒时可提前提示，最多两个。计时包含普通问答和提示语音，到时等当前语音自然结束后揭底。揭底讲解与感谢实际播完后自动下一题，整库轮换用完前不重复。

## 画面、声音与现场恢复

插画底图为`public/turtle-game-background.png`。题目、倒计时、问答、线索及汤底均为HTML实时渲染。适配1080×2400和1080×1920；重要内容在上方80%，小猫仍全画面自由活动、鼠标穿透。

完整题库只在服务端，揭底前公开状态没有完整汤底。刷新恢复当前题目与阶段。题目、线索、轮换记录、原歌曲写入`data/turtle-game.json`，支持保留现场重启。暂停助手会暂停计时并撤销旧AI批次；恢复后续播未完成语音。

语音自然结束使用专用回报，普通`ended`（含失败、中断）不推进。静音、语音失败或浏览器阻止声音时保留当前播报，恢复声音后重试；工作台提供“重试主持播报”。游戏期间礼物舞蹈暂存，返回听歌后继续。

## 验证

- `node --test test/turtle-game.test.js test/turtle-server.test.js test/draw-game-server.test.js`：口令、限流、一万条提问压力、计时、超时、隐藏汤底、语音回报、暂停、重启及歌曲队列恢复。
- `node scripts/verify-turtle-game.mjs`：独立浏览器检查两种画幅、安全区、刷新、静音/失败不跳题、自然语音完成续场。音频使用模拟AudioContext，不代表现场已出声。
- `node scripts/verify-turtle-model-live.mjs`：现有配置真实调用DeepSeek检查六种情形，不向直播发弹幕。
- `node scripts/verify-draw-game.mjs`：原游戏画面、计分和语音循环回归。
