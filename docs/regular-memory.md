# 常客记忆

真实弹幕按昵称在本机记录最近8条有效话题及5首成功入队的歌曲，最多500个昵称，30天无互动后过期。旧版记录自动兼容；测试弹幕不进入记忆。简单招呼和重复话题不会挤掉有内容的原话。

先取得本条消息之前的记录，再保存当前原话，避免把刚说的话当成往事。间隔30分钟再次互动时可自然提起一件往事，每个昵称的主动回忆机会至少间隔30分钟；正常连续聊天不反复回忆。观众主动问记忆时可以直接答，当前话题始终优先。该间隔也会持久保存。

只引用真实原话和点歌，不推断最爱、身份或情感经历；无逐条时间依据时不编造昨天或上次到访。无记录且无近期对话时，被问是否记得会直接坦诚说明。昵称可能重名，不代表经过账号身份验证。

纠正消息不会把旧话题作为当前记忆传给模型，新的纠正原话替换旧话题记录。观众发送完整的“忘记我”或“清除我的记忆”时，删除该昵称在本机的记录并清理待回复和近期对话；后续新互动可重新建立记录。歌曲历史与话题分别保存，不因话题纠正而虚构或删除真实点歌。

验证：`node --test test/audience-memory.test.js test/live-context.test.js test/room-entry.test.js`；`node scripts/verify-regular-memory.mjs` 使用独立模拟观众请求实际模型，不注入直播间、不播放测试语音。
