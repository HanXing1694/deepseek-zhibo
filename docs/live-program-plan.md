# 猜题与音乐节目轮播

2026-11-05，按主播确认的**五场你画我猜 → 听歌10分钟**实施。海龟汤不自动加入轮播。

## 节奏与接管

- 主播弹幕`开启轮播`，或工作台同名按钮：接入当前场景。正在猜题时本场算本组第1场，不重置；正在听歌时先计10分钟音乐，再进入五场猜题。
- 每场六题、每题30秒。第5场的前三名结算、今日领先者与转场邀请合成一段播报，**实际自然播放完成**后进入听歌。不是按估计语音时长切换。
- 听歌时间只累计独立播放器实际向前推进的进度；助手暂停、舞蹈、播放失败和重启空档不计。音乐压低但仍在播放时继续累计。
- 默认10分钟。到时若待播超过5首，自动延长一次5分钟，最多自动15分钟；主播仍可手动再加时。到点后等待当前歌曲原定切歌边界，沿用原有90秒/拥挤队列60秒/单首最多4分钟规则。
- 最后30秒语音预告一次，进入游戏准备画面后播放开场说明，实际播完才开始下一组五场。语音失败、静音或中断不算完成，工作台可重试。
- `停止轮播`：停止后续自动切换，当前场景继续。
- `再玩一场`：本组目标加1，并取消“本场后听歌”的提前切换。
- `下一场听歌`：本场结算播完后转听歌。
- `听歌延长5分钟`：当前音乐段加5分钟。
- 原`返回听歌`仍立即退出游戏，同时停止自动轮播；主播手动进入游戏/海龟汤也会停止轮播。暂停助手保留节目进度。

## 点歌和战绩

游戏中发送`点歌 歌名`会真实核对歌曲并进入同一条播放队列，只有文字回执，不打断主持，也不会把歌曲当成猜题答案。观众歌曲在游戏中正常按顺序播放，沿用原切歌时限；同一昵称最多一首待播，保留冷却、总队列上限、同歌去重及不可播检查。游戏与听歌共享当前曲目，切换只调整场景与音量，不暂停、重播或恢复旧歌。无观众点歌时才从缓存曲库续播，缓存电台遇到点歌让位，已在播的观众歌曲按原规则播放。礼物舞蹈仍在游戏结束后处理，排队礼物不会阻塞游戏中的音乐队列。

本场计分规则不变，公布答案后仍可得本场1分。**今日榜仅累计公布前的分数**：首位2分，其余1分。同题同人只计一次，同分按达到分数的时间先后排序。

按北京时间04:00换直播日，跨日比赛整场归开始日，结算后下一场/音乐场景展示新日榜。保存近30天答对题数、有效参赛场数（至少答对一题）、冠军次数和单场最高分。更新前无法还原的战绩不补造。测试弹幕不进入正式战绩。

观众可发`我的战绩`、`今日榜`、`怎么玩`，显示文字卡片，不插队口播；每人60秒、全局15秒查询间隔。工作台展开今日榜可看前50名。沿用现有昵称关联方式，消息ID不作为用户ID，不自动合并改名或同名。`忘记我`等现有口令也清除游戏记录；当前场结束不会重新补回已清除的战绩。

## 画面与互动

游戏右上角保留本场前三，补充今日前三；顶部显示本组进度。听歌画面显示今日猜题之星和下一组预告。查询卡短暂展示，重要信息不进入底部20%遮挡区；小猫仍自由活动、鼠标穿透。已核对1080×2400、1080×1920及现场1440×2560画幅。

按主播最新要求隐藏观众弹幕口令卡片，保留开场与转场语音说明。画面顶部和控制台直接显示“轮播已开启 / 轮播未开启”，开启时附本组场次或下组倒计时；控制台的“停止轮播”按钮仅在开启时显示。游戏画面显示与同一播放器同步的歌名、歌手和下一首。新版窗口回报`shared-music-v2`，用于核实界面是否已加载。

小鲸的听歌回复可引用近30天真实成绩，最多每30分钟给同一昵称一次可用的战绩回顾依据。节目转场关注提醒至少间隔12分钟，并与普通聊天的10分钟提醒限制共享。成绩不会改变点歌顺序。

工作台展示本组猜题互动人数、猜题后成功点歌人数、跨阶段互动人数和再次参与人数，仅表示实际观察到的互动，不等同观看留存率或关注人数。

## 保存与恢复

`live-program.js`管理节目状态，`game-records.js`管理实际判分与互动记录。`data/live-program.json`按房间隔离，原子保存游戏快照、战绩和节目状态；答对入账与暂停返回前等待存档，重启从共同快照恢复，避免只恢复其中一份。保留原`draw-game.json`兼容文件与现有重启脚本。

保留旧采集页的自然语音完成回报兼容：节目播报同时使用现有完成标识，旧页面可通过原完成接口衔接下一组；泛化的`ended`包含失败/中断，绝不用于自动开场。新版页面才显示榜单、查询卡和节目预告，窗口心跳中的`uiVersion`可区分是否已加载新版。

现场更新使用`scripts/restart-preserving-state.ps1`，核对原游戏/歌曲/队列、监听与实际弹幕、音乐进度、原声音窗口及全屏状态。不会操作开播、停播或推流设置。
